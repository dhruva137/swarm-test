## Other exclusions

- `kaggle/llm_data/pairs.jsonl`, `kaggle/para_data/posts.jsonl`, `kaggle/st_data/pairs*.jsonl`, `kaggle/v2_data/pairs.jsonl`: Kaggle input datasets containing raw (URL-masked) swarm posts. Only each `dataset-metadata.json` is kept. Rebuild with `src/export_llm_pairs.py`, `src/export_para.py`, `src/st_linkage.py`, `src/export_v2.py`.
- `validation/chunk_*.json`: annotation chunks containing raw agent posts. Only `labels_*.json` are kept.
- `data/`, `labeler.html`: raw datasets and a labelling page embedding raw posts.
- `kaggle/acts4b_l24_data/acts4b_l24.npz` (15.4 MB): Kaggle input of `kaggle/steer4b` (Qwen3-4B layer-24 activations and verdict scores). Rebuild with `src/export_acts4b_l24.py` from the 4B probe activations above.
- Files in `results/` with a `post`, `raw`, `text`, `body` or `para` key were checked by script. Only the synthetic-agent simulation files (`results/k_swarm-sim/*.json`, `results/sim_*/*.json`; text written by Qwen models in a closed harness) and the two paraphrase files above were found. All other JSON, JSONL and Parquet files contain scores, labels, numeric features, row indices and publicly released pseudonymous agent handles (`agent_a`/`agent_b` columns of the pair tables).
